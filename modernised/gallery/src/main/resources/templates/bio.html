Bio

Anand Hemadri is a software enthusiast, and a technology consultant, with about 25 years of experience in the industry.

This project demonstrates how a legacy web application can be modernised incrementally using the Strangler Fig pattern rather than being rewritten wholesale.

The original Java/Spring application is retained as a behavioural and visual reference while selected capabilities are replaced slice by slice with a modern Spring Boot implementation. The goal is to preserve working behaviour, reduce migration risk, and make every step independently testable and reversible.

The exercise covers modern persistence, security, server-side rendering, automated testing, static asset handling, observability, containerisation, and eventually AI-assisted engineering workflows. Where the legacy application contains incomplete or accidental behaviour, the modern version preserves intent rather than blindly reproducing defects.

This repository is therefore less about the gallery itself and more about demonstrating a practical approach to legacy modernisation: understand the existing system, establish a baseline, replace one vertical slice at a time, verify parity, and only then retire the old implementation.
